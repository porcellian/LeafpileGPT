# Implementation tasks

Implement one numbered task per feature branch and pull request. Begin each task
on `feature/<task-number>-<brief-description>`. Run the relevant checks, review
the complete diff against its acceptance criteria and specification sections,
mark the checkbox complete in that task's PR, and wait for the user to merge
before beginning the next task. Use conventional commit messages. Never
automatically merge a pull request.

Local game files under `stories/` are for development checks only. Do not commit
them or make CI depend on them. Automated tests must use generated or separately
authorized fixtures.
